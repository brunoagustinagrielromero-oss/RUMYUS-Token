# 🚀 RUMYUS Token (RMS)

**RUMYUS** es un token de estándar ERC-20 desarrollado en Solidity sobre la red blockchain, diseñado con un suministro máximo fijo e inmutable de **20.000.000 RMS**.

---

## 📌 Especificaciones del Contrato

| Parámetro | Valor |
| :--- | :--- |
| **Nombre del Token** | RUMYUS |
| **Símbolo / Ticker** | RMS |
| **Suministro Total (Max Supply)** | 20.000.000 RMS |
| **Estándar** | ERC-20 |
| **Licencia** | MIT |
| **Estado de prueba** | Compilado y verificado en Remix IDE (100% de la emisión asignada al propietario) |

---

## 🛡️ Características del Token

- **Suministro Fijo:** No se pueden crear (minar) nuevas monedas por encima de los 20 millones iniciales.
- **Control de Propietario (Ownable):** Implementa el estándar OpenZeppelin para garantizar la seguridad en la gestión del contrato.
- **Compatibilidad Universal:** Listo para integrarse con billeteras descentralizadas (como MetaMask, Trust Wallet) y exchanges descentralizados (DEX).
